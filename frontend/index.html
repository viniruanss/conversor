Formatos suportados

          
Seis caminhos de conversão entre os três formatos de dados mais usados no dia a dia.

        

 
        

          

            

              
            

            
CSV

            
Dados tabulares separados por vírgula. Ideal para planilhas e exportações de banco de dados.

          

 
          

            

              
            

            
JSON

            
Padrão para APIs e aplicações web. Estrutura de objetos legível por humanos e máquinas.

          

 
          

            

              
            

            
XML

            
Marcação estruturada com tags. Comum em integrações corporativas e sistemas legados.
